# Contributing

Thank you for contributing to Fabric Semantic Model Toolkit. Contributions that fix bugs, improve the toolkit, or clarify its documentation are welcome.

## Getting started

1. Check the repository's issues and pull requests to see whether the work is already being discussed.
2. For a significant feature or behavior change, open an issue first to agree on the scope.
3. Fork the repository and create a branch for your change.
4. Review the README and existing project conventions before making changes.

## Reporting issues and proposing changes

- Search existing issues before opening a new one.
- For a bug report, describe the expected and actual behavior and provide reproducible steps. Include relevant error messages or sanitized examples when helpful.
- For a feature proposal, explain the use case and the problem it would solve.
- Do not include credentials, tokens, confidential customer data, or other sensitive information in issues or pull requests.

## Development guidelines

- Keep each change focused and avoid unrelated edits.
- Follow the code style and architecture already used in the affected area.
- Add or update tests for behavior changes, and update documentation when usage or functionality changes.

## Submitting a pull request

Please include a concise description of the problem and solution, link related issues, and mention any behavior or compatibility changes. Include test results and, where useful, screenshots or sample output. Keep the pull request focused and respond to review feedback.

By submitting a contribution, you agree that it may be distributed under the license applicable to this repository.
